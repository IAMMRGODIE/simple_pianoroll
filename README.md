# simple_pianoroll

一个"简易钢琴窗"小工具：像 FL Studio 那样在网格里编排音符并**实时播放**，但支持**不同的平均律**（12-EDO、19-EDO、24-EDO、31-EDO、53-EDO、纯律、毕达哥拉斯律、自定义比例），用于作曲与调律实验。

基于 Rust + [egui/eframe 0.36](https://github.com/emilk/egui)，音频引擎复用 [i_am_dsp](https://github.com/iammrgodie/i_am_dsp) 的 `Adsr` / `Tuning` / 效果器等 DSP 基础设施，通过 `cpal` 实时输出。

## 功能特性

- **钢琴窗编辑器**：网格绘制音符、三区缩放（左/主体/右）、框选、拖画、按吸附（1 / 2 / 4 / 8 / 16 步或整小节）。
- **多调律实时切换**：垂直方向"每八度行数"随调律改变，音高映射同步更新；切换后自动填入对应的默认音名。
- **可自定义音名**：按八度内每个音级配置拼写（如 `C C# D ...`），未知音级自动回退为数字；支持自定义音高标签。
- **力度（velocity）**：每音符独立力度，底部力度 lane 可视化，可拖拽调整、Alt+滚轮批量调节。
- **音色与采样**：正弦/三角/锯齿/方波 + ADSR + 增益；可加载音频文件（wav/flac/mp3/ogg）作为音源，支持 **One-shot**（不循环）开关。
- **单轨效果链**：低通滤波、延迟，各有开关与干湿比。
- **多 Clip**：多个片段，可命名、增删、切换编辑。
- **项目保存/加载**：JSON 格式，包含谱面、走带、调律、音色、效果、编辑器设置与全部 clip。
- **撤销/重做**：几乎所有的编辑操作（增删、移动、缩放、移调、力度、粘贴……）都可撤销。
- **扫描线预览**：按住 Alt + 右键拖动，竖线扫过的音符实时发声（支持和弦，只触发新进入的音符）。

## 构建与运行

需要 Rust 工具链（edition 2024）。

```bash
cargo run              # 调试构建并运行
cargo run --release    # 发布构建（更流畅）
cargo clippy --all-targets   # 代码检查
```

### 目录结构

项目依赖 `i_am_dsp`（路径依赖），两者平级：

```
C:\projects\dsp\
├── i_am_dsp\              # 上游 DSP 库（workspace）
│   └── i_am_dsp\
└── simple_pianoroll\      # 本工具
    ├── Cargo.toml
    ├── README.md
    ├── Architecture.md    # 架构设计文档
    └── src\
        ├── main.rs        # 应用外壳：面板布局、快捷键、保存/加载
        ├── audio.rs       # 实时音频引擎（cpal 回调 + i_am_dsp 生成器）
        ├── pianoroll.rs   # 钢琴窗编辑器（绘制 + 交互）
        ├── pattern.rs     # 音符/小节数据结构与事件调度
        ├── tuning.rs      # 调律种类与解析
        └── project.rs     # 项目 JSON 序列化
```

## 使用指南

### 钢琴窗编辑（鼠标）

| 操作 | 效果 |
| --- | --- |
| 左键点击空白格 | 添加一个音符（吸附到当前 Snap），并试听 |
| 左键点击音符 | 单独选中该音符 |
| Shift + 点击未选中音符 | 加入选择 |
| Shift + 点击已选中音符 | 原地复制**整个选中组** |
| 拖动音符主体 | 移动选中组（未选中时先单选该音符再移动） |
| Shift + 拖动主体 | 复制选中组并移动副本（原音符不动） |
| 拖动音符左/右边缘 | 调整音符长度（选中组一起调整） |
| Ctrl + 拖动空白 | 框选（再次框选已选中的部分会取消选择） |
| Shift + 拖动空白 | 拖画一个长音符 |
| 右键拖动 | 擦除扫过的音符 |
| Alt + 右键拖动 | 扫描线预览：竖线穿过的音符发声（按住 Alt 时不擦除） |
| Alt + 滚轮 | 调节选中音符（无选中则悬停音符）的力度 |
| 滚轮（网格上） | 上下滚动音高 |
| Ctrl + 滚轮 | 以光标为锚点缩放（最小缩放到整谱 + 1/4 余量） |
| Shift + 滚轮 | 横向平移 |
| 滚轮（标尺顶部窄条） | 横向平移 |
| 滚轮（标尺下部） | 缩放 |

> 点击空白格添加音符时取**行上沿**（pitch 向上取整）；横向滚动时音符与力度条不会盖住左侧音名列。
> 按住 **Alt** 拖动/缩放音符时会**忽略 Snap 吸附**（自由移动/缩放）；音符长度可小于 1 步（连音或自由拖画时）。

### 走带（Transport）

- 顶部面板：**BPM** 速度、**▶ Play / ⏸ Pause**、**⏮ Stop & Home**（停止并回到开头）、**Metronome** 节拍器（音量可调）、**Clear**（清空音符）、**Demo**（载入示例）。
- 点击标尺任意位置可跳转播放头；拖动可扫动。

### 调律（Tuning）

- 顶部下拉切换：Equal 12、EDO 7 / 12 / 19 / 24 / 31 / 53、Just（纯律）、Pythagorean（毕达哥拉斯）、Custom。
- **Custom…** 打开自定义比例窗口：输入每个音级相对根音的比例（`note / root`，如 `9/8`、`5/4`），点击 **Apply tuning** 生效。
- 切换调律后键盘行的数量、默认音名、发声频率都会同步更新。
- 音高范围不再固定限制在 C2..C11：纵向滚动范围按调性以八度计算（-6..+12 八度），53-EDO 下也能写到很高的音。

### 音色 / 采样 / 效果（右侧 Track 面板）

- **Wave**：正弦 / 三角 / 锯齿 / 方波；**Attack / Hold / Decay / Sustain / Release / Gain** 调节包络。
- **Load sample…**：加载音频文件作为音源；加载后显示文件名，可切回 **Use generated wave**。
- 使用采样时显示 **One shot** 复选框：勾选后 sample 只播一遍、不循环。
- **Effects**：Lowpass、Delay，各有开关（on）与干湿比（mix）。

### 多 Clip（顶部面板）

- **Clips** 下拉切换片段；旁边文本框重命名；**+ Clip** 新建、**- Clip** 删除（至少保留一个）。
- 切换 clip 时当前编辑内容会自动保存到原 clip。

### 项目保存 / 加载

- **💾 Save** / **📂 Open**（或 `Ctrl+S`）：JSON 文件，自动补 `.json` 后缀。
- 保存内容包括：当前谱面与全部 clip、BPM、调律与自定义比例、音色与效果、音名方案、颜色方案、Snap、主音（tonic）等。

### 音高与颜色

- 底部面板：**Snap** 吸附、**Clip len** 片段长度、**Color** 配色方案（按音级 / 按八度 / 纯色 / 自定义，**Colors…** 编辑每音级颜色）、**Root** 主音、**Note names** 音名编辑与 **Reset**。
- 选中音符时出现 **Vel** 力度滑块与 **Note label** 自定义标签（覆盖自动音名）。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `Home` | 回到开头 |
| `Delete` / `Backspace` | 删除选中音符 |
| `Ctrl+A` | 全选 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴（粘贴在播放头位置） |
| `Ctrl+D` | 复制选中组（放到选区右侧） |
| `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） | 撤销 / 重做 |
| `Ctrl+S` | 保存项目 |
| `Ctrl+↑` / `Ctrl+↓` | 选中音符上 / 下移一个八度（无选中则全部） |
| `Shift+↑` / `Shift+↓` | 选中音符上 / 下移一个半音（无选中则全部） |

> 在文本输入框（音名、clip 名、比例编辑等）聚焦时，上述快捷键不会触发。

## 技术要点

- UI 线程与实时音频线程通过 `Arc<Mutex<Engine>>` 共享状态；编辑器只对局部 `Pattern` 快照渲染，帧末一次性写回，避免实时回调被 UI 卡住。
- 事件只在**进入新 step 时**派发（避免每样本重复触发 ADSR 导致音符延迟/爆音）。
- 每个音符拆成三个交互区（左缘 / 主体 / 右缘），拖拽语义清晰：边缘缩放、主体移动。
